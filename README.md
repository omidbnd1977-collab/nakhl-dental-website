# کلینیک دندانپزشکی نخل — دکتر صحرا عباسی

لندینگ فارسی RTL برای دکتر صحرا عباسی در کلینیک نخل قشم.

هیرو با اسکرول‌اسکراب سینمایی (GSAP ScrollTrigger + توالی فریم): نمای بیرونی واقعی کلینیک → ورود از دروازه → پذیرش لوکس. ارتفاع سکشن حدود `300vh`، بوم sticky تمام‌صفحه، و فقط موقعیت اسکرول فریم را جلو/عقب می‌برد (بدون autoplay و بدون وابستگی به video seek).

## اجرا

```bash
python3 serve.py --port 3847
```

`http://localhost:3847` — سرور محلی از HTTP Range پشتیبانی می‌کند تا اسکراب ویدیو دقیق باشد.
