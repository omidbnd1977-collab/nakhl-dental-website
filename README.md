# کلینیک دندانپزشکی نخل — دکتر صحرا عباسی

لندینگ فارسی RTL برای دکتر صحرا عباسی در کلینیک نخل قشم.

هیرو با اسکرول‌اسکراب سینمایی (GSAP ScrollTrigger): ویدیوی `assets/videos/clinic-tour.mp4` تمام‌صفحه و sticky است. اسکرول پایین ویدیو را جلو می‌برد، اسکرول بالا عقب می‌کشد، و با توقف اسکرول پخش متوقف می‌ماند (بدون autoplay).

## اجرا

```bash
python3 serve.py --port 3847
```

`http://localhost:3847` — سرور محلی از HTTP Range پشتیبانی می‌کند تا اسکراب ویدیو دقیق باشد.
