# کلینیک دندانپزشکی نخل — دکتر صحرا عباسی

لندینگ فارسی RTL برای دکتر صحرا عباسی در کلینیک نخل قشم.

هیرو با اسکرول‌اسکراب سینمایی (GSAP ScrollTrigger): نمای بیرونی واقعی کلینیک → ورود از دروازه → پذیرش لوکس. ارتفاع سکشن حدود `300vh`، ویدیو sticky تمام‌صفحه، و فقط موقعیت اسکرول فریم را جلو/عقب می‌برد (بدون autoplay).

## اجرا

```bash
python3 -m http.server 3847
```

`http://localhost:3847`
